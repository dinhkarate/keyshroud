# keyshroud brand assets

**keyshroud** = *key* + *shroud*: the key is there and it works, but it is covered.
The mark is a key whose blade hangs under a shroud; the wordmark shows "shroud"
faintly behind a translucent veil, echoing `<redacted:NAME>`.

| File | Use |
|---|---|
| `lockup.svg` / `lockup-dark.svg` | Primary logo (icon + wordmark) on light / dark backgrounds |
| `wordmark.svg` / `wordmark-dark.svg` | Wordmark alone |
| `mark.svg` / `mark-dark.svg` | Icon, avatars, favicon |
| `social-preview.png` | 1280×640 GitHub / Open Graph image (source: `social-preview.html`) |

Colors: ink `#151A2D`, veil `#6D5DF6` (dark mode `#F5F3FF` / `#8B7FFA`), fold `#9A90FB`.
Type: wordmark outlined from [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono)
Bold (SIL Open Font License 1.1); no font is needed to render the SVGs.

Do not combine the mark with Bitwarden or Vaultwarden logos.
